# 🛒 Modern E-commerce Backend API

A high-performance, scalable, and fully documented RESTful API for e-commerce platforms. Built with **Django Rest Framework**, this project follows best practices in software architecture and API design.

## 🚀 Key Features

- **Authentication:** Secure JWT (JSON Web Token) authentication using `SimpleJWT`.
- **API Documentation:** Interactive Swagger UI and Redoc via `drf-spectacular` (OpenAPI 3.0).
- **Product Management:** Support for categories, brands, and inventory tracking.
- **Cart & Orders:** Advanced shopping cart logic and transaction-safe order processing.
- **Filtering & Search:** Powerful filtering capabilities using `django-filter`.

## 🛠 Tech Stack

- **Framework:** [Django](https://www.djangoproject.com/) & [DRF](https://www.django-rest-framework.org/)
- **Database:** PostgreSQL (Production) / SQLite (Development)
- **Documentation:** Swagger UI (OpenAPI 3.0)
- **Containerization:** Docker & Docker Compose (Optional/Planned)
